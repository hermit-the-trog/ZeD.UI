# ZeD-UI docs

Everything written about the mod that isn't the front door. The front door stays at the repo root: README, DEVELOPING,
TRANSLATING, WATCH_ADDON_GUIDE, LICENSE, SUCCESSORS, and the two session-start files, STATE.md and
NEXT_SESSION_HANDOFF.md. The live work queue stays at `ZeDUI/PUNCH_LIST.md`.

| Folder | What lives here |
|---|---|
| `specs/` | The contracts builders work from: each feature's spec, the multiplayer design and decisions, the beta decisions. |
| `reference/` | What you look up by name: the engine quirk bank, the Kahlua and Java notes, the hook map, the glossary, the comment voice, research. |
| `plans/` | Work still in progress: drafts, proposals, the beta QA checklist, open library fixes. |
| `handoffs/` | Dated notes handed from one session or person to the next. Written once, read as context. |
| `archive/` | Finished or retired: done work orders and old copies, kept for history. |

Paths inside the handoffs and older docs that start `mockups/`, `tools/`, `qa/` or `workshop/` are relative to
`ZeDUI/`. Nothing in `docs/` ships to players; the Workshop staging script copies only the mod's version folders.
