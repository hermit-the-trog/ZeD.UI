[h2]Does not work with ZeD[/h2]
These do a job ZeD-GUI also does, in a way that clashes with it: both draw at once, or ZeD's screen replaces the one the mod changes. Run one or the other.
[list]
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3796139100]This Is Your Life - Character Creator Overhaul [B42.21][/url] by MysticaUmbra: A fix for This Is Your Life's clothing screen; the same as This Is Your Life.
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3773911887]This Is Your Life [B42 Stable] WIP[/url]: Loads with no errors, but ZeD's own Looks screen replaces the character creator it changes, so none of its features show. Run one or the other.
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3819012597]Xen's Enhanced GUI[/url] by Xen: Both are whole-interface overhauls. With both on, its HUD (health, moodle bar, compass, quick access) draws over ZeD's belt and moodles, and its inventory opens beside ZeD's windows. Run one or the other.
[/list]

[h2]Broken on 42.21 or 42.22 by themselves[/h2]
These are broken on Project Zomboid 42.21 or 42.22 by themselves, with or without ZeD-GUI. Found a mod that clashes with ZeD-GUI? Reply with its name, its Workshop link and what happened.
[list]
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=2696986935]Barricaded World - Extended Erosion [b41/b42][/url]: Errors as new parts of the map load (it calls PropertyContainer.Is, which 42.21 removed). Not ZeD.
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3036830549][B42/41] Better Clothing Info Comparison[/url]: Its clothing tooltip errors every frame on 42.21 (a nil call in its own tooltip code), with or without ZeD-GUI. Not ZeD.
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=2875848298]Common Sense[/url] by Braven: Stops the world from loading: its recipes ask for a fluid, Alcohol, that 42.21 no longer has. Not ZeD.
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=2835852387]Disassemble Container With Items[/url]: Replaces the game's furniture-moving code with an older copy that calls functions 42.21 removed, so picking up, placing and taking apart furniture error. Not ZeD.
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=2714850307]Horde Night[/url]: Closes the game on 42.21 as a save loads (while saving its own data), with or without ZeD-GUI. Not ZeD.
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=2737665235]Ladders!?[/url] by co`: Its ladder code errors as the world loads (setLadderClimbingFlags). Not ZeD.
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3388107363][B42] Noir's Rifle Slings[/url]: Errors at load on 42.21 (a body location given as text), so its sling slot is not made. Not ZeD.
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=2642486124]Quick Item Action[/url]: Every double-click on an item errors on 42.21 (it calls getTypeString, which 42.21 removed, before any ZeD code runs). Not ZeD.

[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=2640351732]Spear Traps[/url]: Every right-click on the world errors on 42.21, once per item you carry (it calls getCategories, which 42.21 removed, in its own menu code). Not ZeD.
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3403180543]Week One NPC[/url] by Slayer: Its scheduler errors once a game minute in an existing save (generateSchedule). Not ZeD.
