# ZeDUI/tools/qa/regression.txt  (Oct 19 2026)
# The default manifest of zedqa_run.ps1: the bridge QA library, run unattended
# on the ZeD-QA save in the order below, at 1080p windowed or 4K fullscreen.
#
# One script per line, relative to this folder:
#   <script> | <tag> | timeout=<s> | end=<regex> | expect=<regex>    # comment
# Only the script is required. <tag> is the script's "ZEDQA <tag>" prefix (the
# runner reads it from the script's say() when left out); every tag must be
# unique across the manifest (the runner refuses a repeat). timeout= overrides
# -TimeoutSec for that script. end= names the line that ends a script that
# prints no DONE. expect= is an exception the script raises on purpose (it is
# not counted as a failure). Blank lines and # comments are skipped.
#
# Allowlist rule: only in-game scripts that end with a DONE line and put back
# what they add. Accepted leftovers (QA-save conventions): god mode on, the
# character moved beside the pickup, clear weather from the radio captures.
# Never here: anything that makes a save, kills the character, reaches the
# Workshop, runs at the main menu, or needs the real mouse between runs (the
# runner refuses the never-unattended names itself; see the end of this file).
