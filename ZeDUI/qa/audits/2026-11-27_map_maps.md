# Maps tab: map for the gamut sweep (QA, Nov 27 2026)

A read-only map of ZeD's Maps tab (the World window's map: the drawer map, its unfolded window, the marks and notes, the three styles and the Survey colors, the map key, the flyer pins, paper maps read from the inventory) against the game's own world map, its symbols editor, its paper map window and its mini-map (B42 as installed on E:, files dated Nov 9). It maps other mods' map add-ons only as far as the tab's extension hooks reach them. Line refs are as read on Nov 27. Nothing was run.

**The tab is on the World window.** ZeD_WorldWindow.lua declares it in WORLD_TABS as id "maps", key UI_ZeD_World_TabMaps, group 2, after Furniture, always visible (WW:137); MapsTab registers its renderer in the dispatch table (MT:2663-2665, WW:1907) and its focus stops come through WW's tab builder (WW:1247-1252). Its focus zone is worldTabContent; the unfolded window has its own zone popMapContent (MT:2583-2586, FM:1174-1175). The game's full-screen world map never shows while ZeD runs outside safe mode (OWM:118-149), and the game's mini-map is hidden (OMM:24-37).

Short names (ZeD, 42/media/lua/client/ZeD/ unless noted): MT MapsTab.lua, MX MapsTabExt.lua, MK MapsTabKey.lua, MS MapsSurvey.lua, SD MapsSurveyData.lua, MN MapNotes.lua, PM PaperMap.lua, FL FlyerMap.lua, OWM Overrides/WorldMap.lua, OMM Overrides/MiniMap.lua, OPM Overrides/PaperMap.lua, OW Overrides/Wheels.lua, WW ZeD_WorldWindow.lua, DW ZeD_DpadWheels.lua, LO ZeD_MpLeftovers.lua, PP ZeD_PrintPage.lua, RD ZeD_Reader.lua, FM Input/FocusManager.lua, ID Input/InputModeDetector.lua, ZUI shared/Translate/EN/UI.json (ZeD's words).
The game's files (media/lua unless noted): ISWM client/ISUI/Maps/ISWorldMap.lua, ISWMS client/ISUI/Maps/ISWorldMapSymbols.lua, ISWMK client/ISUI/Maps/ISWorldMapKey.lua, ISM client/ISUI/Maps/ISMap.lua, ISMM client/ISUI/Maps/ISMiniMap.lua, RWM client/TimedActions/ISReadWorldMap.lua, RMI shared/TimedActions/ISReadMapItem.lua, IPCM client/ISUI/ISInventoryPaneContextMenu.lua, IPN client/ISUI/ISInventoryPane.lua, EQ client/ISUI/ISEquippedItem.lua, DPW client/ISUI/ISDPadWheels.lua, MSYM shared/Definitions/MapSymbolDefinitions.lua, SBX shared/Sandbox/Apocalypse.lua.

## 1. What the tab does

**Getting there:**
- The World window's tab strip, tab "maps" (M). The drawer is 480 units (WW:1876), the half card 220 when held in (WW tabCardW and heldIn, near WW:2250-2265). The map is built on the tab's first draw and kept for the window's life (MT:1777-1793); while another tab is up it is hidden (WW:4857-4861).
- The Map key. The game's key handlers stay the game's (ISWM:1658-1721: player 0 only, refused while paused unless the game's own map is up, ISWM:1647-1650). A tap calls ISWorldMap.ToggleWorldMap, which ZeD wraps (OWM:137-149): with ZeD's world map unfolded it folds it at once (no light check, as the game's close); else the game's Toggle runs: Allow, the light rule, the split-screen death rule, then ISReadWorldMap (50 ticks, read pose, MapOpen; RWM:12-18, 34). Its perform calls ShowWorldMap, wrapped (OWM:118-124): the World window opened if shut (and marked as the map's own), switched to Maps and unfolded (OWM:33-79), then centered and zoomed where asked (OWM:84-101).
- Holding the Map key 500 ms: the game's radial, World map only (the mini-map slice is dropped by ZeD's wheel, OW:138-140; ISWM:1674-1702).
- The D-pad World wheel: the Map slice runs the same ToggleWorldMap, greyed "No world map" where it is not allowed (DW:1158-1161, 1218); the Tabs slice lists Maps among the tabs (DW:1129-1153, H.worldTab DW:823).
- The HUD's equipped-item map button (EQ:452, 1227) and the game's own D-pad wheel slice (DPW:74) call ToggleWorldMap.
- The unfold button on the tab's header opens the same window without the read action (MT:1334-1348, 1835-1840).
- Read Map on a map item (the right-click option, a double-click, IPN:1108) ends in ISInventoryPaneContextMenu.onCheckMap, which ZeD replaces (OPM:23-32): a map in a bag or on the floor goes through the game's transfer first, then ZeD's paper window opens (PM:54-99). See suspicion B1: the game's own onCheckMap now queues ISReadMapItem (IPCM:2661-2670), which ZeD never runs.
- Show on map from the reader or the Journal's Papers: the places become known, then ISReadWorldMap with a center and zoom (PP:583-597, RD:599); ZeD's map opens there and pulses the spot (OWM:94, FL:277-280).
- A stash map's Find button on the band (PM:269-299).
- Not here: split-screen players without ZeD windows (ZeD.windowsFor, Atoms.lua:1984-1987) get the game's map and paper window (OWM:35, 128, 138; PM:68). A mod listed in ZeD.WorldMapHook.vanillaWhen gets the game's Show (OWM:107-120; ModSupport/CustomMapLabels.lua).
- Safe mode: Show, Hide, Toggle and onCheckMap hand back to the game (OWM:119, 128, 138; OPM:24); the mini-map comes back (OMM:26, 58); a sharing card falls back to the game's panel (LO:203). The tab itself has no safe-mode branch.
