Full / Simple = 完整 / 簡易; Verbose = 詳細. The belt = 腰帶, the drawer = 抽屜, the card = 卡片, the wheel = 輪盤.

Workshop = 工作坊 in prose; Steam stays Steam. Mod profile = 設定檔. Pin (load order) = 釘選; Pin (skills, map tools) = 釘選 too.
Hutch = 畜欄 and hatch door = 孵化門 (game words). Trunk = 後備箱 (game word). Dashboard = 儀表板.
Line 1408 (the prepper's About text) keeps deliberate typos: 內和 (kernel), 切聽, 破部不了. Check it reads as rough and human, not as a real error.
Date lines: month names are "4月" style numerals, order 年 月 日 as in Taiwan; line 717/1444 expect %1 to be the numeral month.
Units kept as the English writes them: kg, L, ml, km, m, psi, cal, MHz; hour/minute words are written out (小時, 分鐘).
Pixel-face lines (radio and dashboard readouts, action bar) are in Chinese at the English's length limit; check they fit the face.
SELECT button (2697) is 選擇; please confirm Taiwan players call it that on the controller.
Doubtful: 網戀詐騙 (Catfish), 烘焙義賣, 迪克西木屋, 巫師城堡 (poster story names, no game word); 暴雷 (Spoiler block); 3 other sandbox names not in the game file are my own wording (e.g. 末日後的月數).
