ZED-UI · VEHICLE DASHBOARD v1 · LUA-FLAT PREVIEW · S123 · DESIGN FOR DIRECTOR REVIEW

Replaces ISVehicleDashboard (hooked at ISPlayerDataObject.vehicleDashboard / OnEnterVehicle). Bottom-centre strip, 560×92 px at 1×. Left: cluster (speed, gear, RPM, fuel). Right: eight toggles, each a status dot + name + key hint. The 3px trim band at the top is derived from the vehicle's paint (HSV → accent); the family changes emphasis only, never the layout, so there is one organism to learn. Gamepad: the strip registers as a focus window while seated — D-pad moves across toggles, A toggles, B releases focus back to driving. Mouse: click a toggle.

States: dot green = on / locked / running; grey = off; yellow = partial (some doors locked, fuel < 35 %); red = fault (no key, no radio installed, fuel < 15 %, engine trouble). Fuel and battery only read while the key is in or the engine runs (vanilla rule). Engine chip colour follows engine condition when running. Low fuel pulses the FUEL row with the danger sine (0.08–0.25 α) rather than a flashing icon.
