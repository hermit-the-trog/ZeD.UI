Before it goes up

  1. Hosting. Steam only shows description pictures from a public web address. Upload the files in ZeDUI/workshop/desc/ (and the full cards they link to, under full/) and replace IMG_BASE in workshop_description_layout.bbcode with that address. The repo's raw files work if the repo is public; Steam artwork uploads work too, but each picture then has its own long address.
  2. Length. Steam allows 8,000 characters. The count under the description estimates it with a typical address in place of IMG_BASE. If the real addresses are long, drop the links around the seven cards first: they only open the full card.
  3. Rebuild. After the gallery or the text changes: py -I ZeDUI/tools/release/make_desc.py, then py -I ZeDUI/tools/release/make_page_mockup.py.
