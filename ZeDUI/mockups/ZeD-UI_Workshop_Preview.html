ZeD-UI replaces Project Zomboid's entire interface. Not a skin. Not a reshade. A complete UI built from the ground up.

Zero Day User Interface. Running on ZeD.UI 7.1.2b — a hacked kernel inspired by a fictional 1993-era operating system that never existed but should have. Think Microtosh System 7.1.2 from an alternate timeline where the desktop wars went differently. Hard geometry, visible window chrome, pixel-precise borders. Every panel, every list, every button has been redesigned from scratch using a component architecture that reads theme data fresh every single frame.

If you've ever wished PZ's interface felt like it was designed by someone who actually thinks about hierarchy, affordance, and information architecture — that's what this is.

This is not a UI skin.

Most UI mods for Project Zomboid restyle the existing panels — new colors, new fonts, adjusted spacing. The vanilla code runs underneath, and you get a fresh coat of paint on the same architecture.

ZeD-UI throws all of that away.

Every panel is rebuilt from scratch using a hierarchical component library: Tokens feed into Atoms which compose into Molecules which assemble into Organisms. The entire system reads its theme data fresh every frame — change your accent color and everything updates instantly, everywhere, with zero stale state.

Two Windows. That's It.

The entire PZ game interface collapses into two mirrored windows:

Character Window — "me and my stuff." Inventory, equipment, health, skills, protection, thermal status, journal, identity.

World Window — "the world and its stuff." Loot containers, crafting, building, foraging, fishing, animal husbandry.

Four draggable objects on your HUD. No docked panels. No floating button strips. No UI clutter competing for your attention during a helicopter event.

Gamepad-Native. Not Gamepad-Tolerant.

ZeD-UI is built by a gamepad player. Not adapted for one after the fact — designed for one from day one.

Every interaction works with a controller. Tab switching, drawer navigation, item selection, drag and drop, context menus, action strip verbs — all reachable without touching a mouse. Button badges update live to match your controller.

If you play PZ on the couch, on a Steam Deck, or with accessibility controllers — this mod was designed with you sitting in the chair.

The Drawer Kills Tooltips

Tooltips are gone. Not hidden — eliminated.

Select an item and the drawer opens with a full Item Card. Select a tab and the drawer shows that content instead. The killer feature is snap-back: open Health, grab a bandage, apply it, and the drawer snaps back to Health showing the wound now bandaged. You never lost context.

80+ Theme Combinations (300+ at Launch)

3 base themes. 9 accent colors. 3 text sizes. 81 base configs — 324 with colorblind modes at launch. Switch at runtime — no restart.

Microtosh System 7.1.2

ZeD.UI 7.1.2b is a hacked kernel running a fictional operating system from 1993. Striped title bars. Close boxes. Grow boxes. Groove dividers. WindowShade. Hard geometry everywhere.

The early-90s desktop visual language solved real problems that modern flat design forgot: every element communicates its function through its appearance. The result is a UI that feels like it was running on hardware that died in 1993 and somehow survived the Knox Event.

Nobody Gets Left Out

Colorblind modes on day one. Protanopia, Deuteranopia, Tritanopia, Achromatopsia. Purpose-built palettes, not a filter overlay.
Dyslexia-friendly typography. A dedicated text rendering mode that improves readability for dyslexic players.
Zero added flashes. Zero distracting animations. The interface is calm. The zombies are not. That's the correct division of labor.
High Contrast as a base theme. Not a toggle buried in a submenu — built with the same care as Dark and Light.
4.5:1 minimum contrast. Three font sizes. Full gamepad and alternative controller support.
Games are for everyone. That includes the people most games forget about.
