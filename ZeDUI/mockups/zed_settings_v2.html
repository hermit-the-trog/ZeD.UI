ZeD setup: grouped, with the control each setting needs

Today the page is sixteen dropdowns under one heading. Here they sit in five groups, and each gets the control that fits it: switches for two or three choices, on/off switches for the two troubleshooting settings, the nine accent swatches for colours, a stepped slider for UI scale, and dropdowns only where the list is long. Click anything: theme, accent and text size preview live on the window, as the real page does. Hover a row for its help text in the band at the bottom. The square at a row's left edge marks a setting changed from its default.

The groups

  • Look: theme, accent, text size, UI scale. What changes how everything reads.
  • Windows: the inventory and equipment views, and each window's own accent.
  • HUD: moodles, watch, action bar. What sits on the game screen.
  • Controls: context menu style, button prompts, input mode.
  • Troubleshooting: Safe mode and the test language, last, where nobody flips them by accident.

Which control, and why

  • Switch (2 to 3 choices you compare): theme, text size, views, moodles, watch, action bar, context menu.
  • Swatches: the nine accents you can see before you pick; the window accents add "Same as Accent color". No free colour picker: the themes are only tested with these nine.
  • Slider: UI scale is a quantity; the steps are the existing ones, Auto at the left, and the readout says what Auto picks on this screen.
  • Dropdown: button prompts (six choices) and input mode lock stay lists.
  • On/off: Safe mode turns red when on, since it switches ZeD off.

What it changes in the code

  • Settings.lua keeps every option and its saved value: ModOptions stores a combo as its item's number, so the files players already have keep meaning the same.
  • The Options window draws ZeD's rows with the new controls (it already draws ticks, sliders and swatches for vanilla's pages); a row says which control it wants.
  • The groups are section bars the page already supports ("ZeD's look" today).
  • Controller: left / right steps a switch, a slider or the swatches; A flips an on/off; the dropdowns open as now.
