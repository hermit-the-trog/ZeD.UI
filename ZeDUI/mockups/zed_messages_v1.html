What is caught

  • Notes (one OK button) made with the game's dialog classes: ZeD already redraws these as its prompts, so it can keep them instead.
  • Mod windows that are notes in all but name (Horse Mod's warning): caught by the "Send to Messages" button ZeD adds to their title bar, then caught every time.
  • News that mods show at the main menu (changelog windows).
  • Lua errors, counted per mod from the game's own error list, with the first lines for a bug report.

What is not

  • Questions (Yes / No, a text box) still ask at once, as ZeD prompts; they are copied into Messages after the answer.
  • ZeD's own prompts, the game's tutorial and death screens.
  • Floating text over the character (halo text) stays where it is.

Where it opens

  • In game: the envelope on the belt (a count when something is new), the ZeD wheel's Messages slice on a controller.
  • At the desk: ZeD menu, Messages.
  • Options, ZeD setup, Messages: catch notes (on), show a toast (on), per mod "show as pop-ups".
