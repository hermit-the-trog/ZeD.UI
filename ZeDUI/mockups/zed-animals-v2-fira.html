v1 mockup — decisions made, open questions, next steps

Decisions I made so you can redline them

  • Hunt sub-mode — tab exists but I didn't design its panel. Scope deferred. Hunt is a separate architecture problem (tracks roster, wild animal designation zones, trap roster) and doesn't belong in v1.
  • 3D avatar — placeholder 110×135 panel. Assumes ISCharacterScreenAvatar reuses with setCharacter(animal) swap per vanilla ISAnimalUI.lua:369. If that's wrong we swap for a portrait icon from the vanilla library and lose avatar motion.
  • Alert polling — rebuild alert list on EveryOneMinute + instant refresh on tab open. Cache between ticks. Comment in Lua, no visible UI mechanism.
  • Stress source inference — simple list of plausible contributors ("sources: hunger · recent gunshot"). No confidence ranking. Easier to build, harder to get wrong, more honest about uncertainty.
  • Alert quick-actions — kept them. [Milk] [Shear] are primary buttons; [Go to] is the default drill-down. Worth the extra Lua per verb for scanability.

What you're looking at, frame by frame

Frame 1 — Overview. The landing. Attention rises to the top (5 animals in trouble). Zone summary next, with food/water mini-meters. Totals last. One-click create-zone and map-view at the bottom. This solves the #1 cross-zone pain point — "are any of my animals in trouble anywhere?" — on frame one.

Frame 2 — Zone Roster. Drill into one zone. Top shows zone identity, food/water/shelter meters, male-on-male warning (fixes pain point #8). Sort tabs let you reorder by any attribute. Each row is species portrait + name/breed/sex/stage + health/hunger/thirst/stress as compact K22 Xanthus numbers + a condition tag on the right. Clucky appears in the list with an "In hutch" tag — fixes pain point #3 directly. Bulk actions at the bottom prepare the architecture for multi-select later.

Frame 3 — Animal Detail at Animal Care Lv 7+. Five bands: Vitals, Production, Breeding, Genetics, Relationships. Avatar top-left, action strip top-right (Grab / Milk / Pet / Rope / Rename). Stress shows numeric value + inferred sources (pain point #2 and #6). Udder URGENT with health-loss notice (pain point "hidden udder damage"). Pregnancy progress bar with day estimate. Genetics band shows "Lv 7+ revealed" — the gate is visible, which means lower levels see "Genetics locked — reach Animal Care 7 to inspect" instead, creating the progression hook. Acceptance meter shows threshold labels (40 for calls, 50 for petting) — pain point "invisible thresholds."

Frame 4 — Butcher. Three hooks, each with full status. Bleeding progress bar shown mid-drain. Engine-bug callout is plain-visible in the UI — we tell the player about the 0.6 body-size hook bug rather than hiding it. Corpses nearby surfaces at the bottom for quick butcher-or-hang decisions.

Friction I noticed while drawing this

  • The detail card is long. Five bands stacked vertically plus identity block plus action strip = a lot of scroll at 480px wide. Either we live with the scroll (Finder Get Info does) or we need a second-level tabstrip inside the drawer ("Vitals / Breeding / Genetics / Social"). Prefer the scroll — a second tabstrip is a level of nesting we've avoided elsewhere.
  • Roster row is info-dense. Name/breed/sex/stage on line 1, four stat chips + condition tag on line 2. Readable, but the condition tag competes with the stat chips for attention. Might want to pull condition up to line 1 as the leftmost element, or drop it entirely and rely on the urgent-flag column for signaling.
  • Stress sources list could get long. "Possible causes: gunshot, rain, hunger, zombies, above ground" on a short-width line wraps badly. We may need to cap it at top-3 contributors or put it in a tooltip instead of inline text.
  • The "+1" baby count in Zone Row totals is subtle. Might not read — could become "4 adults · 1 baby" written out instead.
  • Male-on-male warning in Frame 2 is single-species ("2 rams"). What happens if you have 2 rams AND 2 bulls AND 2 boars in one zone? Needs a multi-line or list format. Easy fix later.

Icons

Species portraits are geometric SVG placeholders I drew — they'll get swapped for the real Item_CowBlack.png, Item_PigBlack_Piglet.png, Item_Chicken_HenWhite.png set when we wire to Lua. Action-strip verbs map to existing AnimalActions_*.png icons (Grab, Kill, Milk, Pet, Rope, Shear, Stats). Alert flags are generic triangle/circle/check SVG — we can swap for ZeDIecon equivalents if you prefer.

What I need from you before v2

  • Thumbs up/down on the overall architecture (three-level drill-down, Overview as landing)
  • Thumbs up/down on the five-band detail card and whether scroll-vs-tabstrip is acceptable
  • Whether the stress source inference is worth the complexity or if we should ship with just the numeric value and figure it out in v2
  • Any band order changes — Vitals → Production → Breeding → Genetics → Relationships might not be your priority order
  • Whether Hunt deserves its own mockup in v2 or stays deferred
