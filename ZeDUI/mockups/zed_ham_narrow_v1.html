In the World window's radio tab | 4K, 2x, the tab as narrow as a walkie's

When it is used

The wide set is used whenever it fits. The narrow one only where the tab cannot hold 400 at the plates' size with the inventory open beside it:

  • 1280 and 1366 wide screens at UI scale 1.0 and up (on 1280, also its own scale with Large text)
  • 1600 x 900 at UI scale 1.5 and up (1.25 with Large text)
  • 1920 x 1080 at UI scale 1.5 to 2.0
  • 2560 wide at UI scale 1.75 to 2.0 (1.5 with Large text)

At your 4K setup (UI scale 1.75) the wide set always fits.

The narrow set fits wherever a walkie fits. Only screens 1600 px wide or less at UI scale 1.5 fit neither: there both draw one size step smaller.

The tab narrows with it, as it does for a walkie, and the radio's name shows in the header only when it fits whole. Full view keeps the wide set: it stands on its own over the world.
