▌ S119 v16 — PROGRESS STATES
Item Card — Progress Band for Active Actions
New element: a Progress Band that lives between the back-bar and flag strip, visible only when an action is active. Same band handles cooking, reading, repairing, washing — and danger states like burning. Color shifts to red when the action is going wrong. Back-bar verbs grey out while action is active so the cancel [✕] in the band is the only way to stop. The relevant top-stat row also shifts text + color (COOKED → "Cooking..." → "Burning...") so a glance tells you everything without reading the band.

Three states of the same steak below: idle raw (no band), cooking (band active, accent), burning (band danger). Pattern extends 1:1 to other timed actions.
IDLE RAW · IN INVENTORY Raw Steak (no action active)
Baseline. No action active, no progress band, card flexes shorter. COOKED stat reads "No" (dim). Primary verb EAT is enabled — risky raw, but allowed. This is the control state to compare against.

▌ PATTERN EXTENSIONS
Same band, different label and target stat:
READING a book → label "READING", time "38 MIN LEFT", target stat PROGRESS: 47/120 →; cancel = stop reading.
REPAIRING a weapon → label "REPAIRING", time "0:45 LEFT", target stat CONDITION: 78% → 95%; cancel = abort repair.
WASHING clothes → label "WASHING", time "1:00 LEFT", soil chips dim out as the bar fills; cancel = take clothes out wet.
BREAKING a weapon mid-fight → danger band, label "FAILING", target stat CONDITION drops fast; no cancel (irreversible).
