Mod folders, separators and the load order tools

New in v2 (scenes e to h): tools for a very long load order. Find on the Load order page filters to the matches and keeps each mod's real place number, with the gaps counted. Load first / Load last pin a mod to the top or bottom block, whatever else changes; a pin never breaks a requirement (what it needs is carried along). Load after... / Load before... open a searchable picker and keep the choice as a rule that Auto and profile loads respect. Rules: MODS_LOAD_ORDER_SPEC.md. Scenes a to d are v1's, unchanged except that the load order now has Find.

Two ways to sort, kept apart. Folders sort the collection on the Mods page: every installed mod, on or off, from the same file [B42]Mod Folders uses, so a player's layout carries over and still works without ZeD. Separators sort the load order on its own page: headings where place is order, saved with each profile; turning one off turns off its mods. The two never touch, except for one button that starts a profile's separators from the folders. Rules: MOD_FOLDERS_SPEC.md.

Questions for you: the load order tools (new)

  1. RECOMMENDFind filters the load order to the matches, real place numbers kept, the gaps counted ("38 more"), A / Return shows the match in the full list. OR keep the full list and mark the matches, Return jumps to the next one. OR a switch for both.
  2. RECOMMENDLoad after... is a kept rule, kept by Auto and profile loads, shown on the row ("Rule") and in the detail, dropped by a manual move (with Undo). OR a one-time move, nothing remembered. OR a tick "Keep this as a rule" in the picker.
  3. RECOMMENDA pin or a rule beats a mod's own load-after wish with no yellow mark; the detail says the wish is overridden. OR the row stays yellow as a reminder.
  4. RECOMMENDPins and rules are kept with the list in use even with no profile. OR only in profiles (greyed until one is saved).
