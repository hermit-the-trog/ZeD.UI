The Voltron

B's chassis: 52×52 icon grid, 8 columns, D-pad native. Status dots (green/amber/grey). Category bar with LB/RB bumpers.

C's brain: Default mode = AVAILABLE (only craftable + near-craftable). Type to search everything. "ALL" chip overrides to show full catalog. Mode label switches green/amber/grey.

D's gravity: Fixed top card + craft button. Structurally impossible to scroll the Craft button offscreen.

Utility strip: Universal dock above the footer. Holds pinned recipe shortcuts on the World Window. On the Character Window, this same slot holds moodle icons. On either window, it could hold search bookmarks, quick-transfer targets, or anything persistent.

The Utility Strip — Architectural Seed

CHARACTER WINDOW WORLD WINDOW ┌───────────────────┐ ┌───────────────────┐ │ content │ │ content │ ├─ UTILITY: moodles ┤ ├─ UTILITY: pins ┤ ├─ footer ──────────┤ ├─ footer ──────────┤ └───────────────────┘ └───────────────────┘ Same 28px strip, same position, different payload. Moodles = character status shortcuts. Pins = crafting/action shortcuts. Both clickable. Both persistent across state changes.

Pin interaction: X button (gamepad) or click ★ pins/unpins selected recipe. Pinned items appear as 22px icon tiles in the utility strip with green/red status dots. Click a pin → selects that recipe in the Now Playing region above.

Ghost slots — dashed-border empty tiles show available pin capacity. Communicates "you can put things here" without text.

Separator — a 1px vertical divider between pins and other future strip content (search bookmarks, etc).

Pixel Budget

Category bar: 24px Toolbar: 26px Now Playing: ~90px (card 34 + action 24 + pills 24 + pad 8) Grid: ~210px (3.5 rows when NP open, ~310px when closed) Utility strip: 28px Footer: 16px Tab strip: 28px width (vertical, no height cost) ───────────────────── Total: ~394px content + 46px chrome = 440px
