When it takes effect

  • NOW as soon as you apply.
  • NEW PLACES only rooms, containers, cars and areas you have not been to yet. What you already found stays.
  • NEW CHARACTERS only a character made after this, for example after a death.
  • FIXED used once, when the world was made. Changing it now would do nothing, so it is locked and greyed.
  • CAREFUL can make the save harder or stranger. You can change it back.
  • CAN'T UNDO deletes or ages something for good.

Apply, history, undo

  • Nothing changes until Apply. A dot marks each changed setting; the Changed page lists them all.
  • Apply asks first in the strip at the bottom and names anything marked CAREFUL or CAN'T UNDO.
  • The save keeps them: the game writes them when it next saves.
  • History keeps every change with the in-game date, kept in the save. Put back sets a setting to what it was.
  • Settings added by other mods appear on their own pages, with their own help text.

Controller

  • LB / RB walk the pages, D-pad up and down picks a setting, left and right change it.
  • A opens a list or a number, X applies, Y opens Find, B closes (asks first if anything changed).

Multiplayer

Single player first. On a server, only an admin would see the line, and the window would send the changes to the server. That part is not tested yet.
