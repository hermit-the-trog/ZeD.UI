Mods: a mod's settings, and picking files one by one

Two additions to the Mods screen you already have. The info pane gets tabs: About (what it shows today), Options (the mod's own settings, changed right there with the same rows the Options window draws) and Sandbox (the settings it adds to each new game). And when two mods ship the same file, a conflict can be settled file by file instead of only by load order. Every mod, setting, help text and file shown here is real, from your own subscriptions.

A mod's settings

  1. RECOMMENDTabs in the info pane: About, Options, Sandbox, Conflicts. Each shows its count, and a tab the mod has nothing for is greyed out. Stacking everything in one long pane does not hold up: AAA Modern Firearms System adds 303 sandbox settings.
  2. RECOMMENDOptions change right there and are kept, exactly as in the Options window (the same rows, the same saving). The option under the pointer is explained in the band at the bottom, in the mod's own words, with its default. A dot marks what you changed since the screen opened. Defaults puts back this mod's options only. Open in Options jumps to the same rows there.
  3. LIMITA mod's options exist only while it is on. Its own code makes them, and that code only runs for mods that are on. For a mod that is off, the tab says so and offers Turn on. A few mods build their own settings window instead of using the game's list; ZeD cannot show those.
  4. RECOMMENDSandbox settings are read from the mod's own files, so they show even for mods that are off: each setting, its default and the mod's help text, and the page it appears on when you start a game. They are chosen for each game, so here they are read only. In a game, they are in the Sandbox settings window (the mockup waiting for your approval).
  5. How ZeD knows which settings belong to which mod. Of your 747 subscribed mods, 114 have options and 213 add sandbox settings. Sandbox settings are easy: they sit in the mod's folder. Options are not: only 47 of the 114 name them after the mod. ZeD would note which mod's file sets each one up as the mods load, the way Messages knows which mod opened a note. That needs ZeD to start watching before the other mods load; to be tested.

Picking files one by one

  1. RECOMMENDPick file by file, on the conflict itself. The picker lists every file the two mods share, which copy runs now, and for the selected file both copies side by side with the lines that differ marked. You choose a copy per file. Load order still decides everything you do not pick.
  2. How it works: ZeD comes with a small empty helper mod, ZeD picks, that always loads last. For each file you pick, ZeD writes that mod's copy into the helper; being last, the helper's copy is the one the game runs. For items and recipes, the helper carries the picked version in a file named so the game reads it last. ZeD rebuilds the copies at the main menu each start, so a mod's update reaches its picked files and a ZeD update cannot lose your picks.
  3. LIMITCode and script files only. The game lets a mod write text files, not pictures, models or sounds, so those clashes stay load order only.
  4. LIMITSingle player only. A server checks that everyone's code files match its own, so a personal pick would keep you from joining. A host could share the helper with every player; not planned.
  5. LIMITMixing can break a mod when its other files expect its own copy. The picker says so before you confirm; any error lands in Messages, and Undo picks puts it back in one press. Still to test: whether a reload is enough for new copies or a restart is needed.
  6. RECOMMENDSame file, same text: not a conflict. ZeD compares the copies. Constown B42 and New Hartburg both ship WorldFiller_pineville.lua, word for word the same; today that shows as a conflict. It would get a grey note instead of a warning.
  7. YOUR CALLWhere picks are listed. Shown here in each mod's Conflicts tab and as the ZeD picks row in the list. A Picks tab beside Conflicts would put them all in one place.
  8. Controller: the info pane's tabs are stops like the list's tabs; in Options, left and right change a value in place, as in the Options window; in the picker, A chooses the copy for the selected file.
