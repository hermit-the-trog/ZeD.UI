Settings: the game's Options, organised, and ZeD setup

The game's Options, regrouped the way a current game does it: Display, Graphics, Audio, Controls, Gameplay, Interface, Accessibility, Mods. One Find across all of them; each setting is one row with its control in the row; the row you point at (or the controller rests on) is explained in the band at the bottom with its default and when it applies; a changed row gets a dot and its own Reset to default. Settings ZeD makes pointless stay in place, greyed, saying Does nothing with ZeD active and why. ZeD setup (Mods > ZeD-UI, and offered on first run) sets in one place the game settings ZeD's look depends on, each row naming the game setting it changes. Last, the Large text size measured on a crowded list, and the fix. Setting names and values are the game's own (42.21).

Decisions for you

  1. RECOMMENDEight groups instead of vanilla's eight pages. Vanilla's pages are named by where the code sits (Display & Performance holds the highlight colours; the UI page holds the camera, the cursor, the reticle and the clock; Accessibility holds auto-drink and the key left in the ignition). The groups follow what a player is looking for: Display (the screen), Graphics (what the world looks like and costs), Audio, Controls (keys, controller, mouse), Gameplay (camera, aiming, cursor, what happens on its own, multiplayer), Interface (text, HUD, clock, language), Accessibility, Mods. Nothing is dropped or renamed; the table below shows where each vanilla setting goes. Vanilla's own MainOptions stays the engine (as today), so Apply runs vanilla's rules.
  2. RECOMMENDOne row, one setting, the control in the row: drop-down, tick box with On / Off, a segmented choice when there are 2 to 4 values, volume as ten blocks, sliders with their number, key caps for bindings. Left / right on the D-pad changes the value in place; A opens a drop-down or toggles. A changed row gets the dot (as today) and Reset to default at its end; the group header has Reset all to default for that group only.
  3. RECOMMENDThe help band says what the pointed row does in one line (vanilla's own tooltip where it has one, plain words where it has none), its default, and when it applies: at once, after Apply, or after a restart. No pop-ups: the screen-size "keep these settings?" countdown and "restart needed" stay strip states, as built.
  4. RECOMMENDApply and Discard in the footer. Back with changes, or Discard, asks in the footer: "Discard 3 changes?" Keep editing | Discard. Apply keeps the window open; the old Accept (apply and close) goes: Apply then Back is two presses, and players stop wondering which one saves.
  5. RECOMMENDSettings that do nothing with ZeD active stay where they are, greyed, the control dimmed and inert, "Does nothing with ZeD active" at the row's end and the reason under the name ("ZeD draws its own context menu: use Text size in ZeD setup"). Players who read a guide for vanilla still find them. A setting that still works outside ZeD's windows (the dyslexic font) is not greyed: it says Only outside ZeD's windows.
  6. ALTERNATIVEGather the pointless ones at the end of each group under "DOES NOTHING WITH ZeD ACTIVE (4)", folded. Tidier, but the rows move away from where vanilla players look for them.
  7. RECOMMENDZeD setup is the first page under Mods > ZeD-UI, and it opens by itself the first time the game starts with ZeD on (a band at the top says so; the footer reads Not now | Use these settings). Every row that changes a game setting names it under the row ("Game: Interface | Moodle size"); ZeD's own settings name nothing. Changing it here changes it there: one value, two places to reach it.
  8. YOUR CALLWorld highlight colours follow the accent (the container and item outlines in the world): offered in ZeD setup as "Accent" or "The game's own". It ties the world to ZeD's colour; some players will want vanilla's yellow back. Default shown: Accent.
  9. RECOMMENDLarge text: apply its size once. See the audit below: today Large's rows are already sized for Large (34) and then multiplied by Large's 1.15 again (39), so text grows 15% while rows grow 30% and four rows in twenty fall off a full bag. The fix and the truncation rules are in the Large scene.
  10. Controller: LB / RB walk the groups (as today's pages), D-pad up / down the rows, left / right the value, A selects, X is Reset to default on a changed row, Y applies, B goes back (asks first when something changed). The footer names them.

The Large text audit

  1. Today (Tokens.lua): Large sets its own heights (row 34, button 30, title bar 30, tab 28, input 30) and then multiplies every token by its scale 1.15 (T.px uses root x 1.15). Rows come out at 39, buttons 35, title bars 35. Text is not multiplied (it draws at its own px x root): body 15, data 13, chrome 13, heading 17. So rows grow 30% and text 15%: the look is airy, and a 20-item bag in an 800-tall column shows 16 of its 20 rows (Small shows all 20).
  2. Fixed widths: the weight column is 40 x scale (46 at Large): "12.50" in 13 px Fira Mono needs 39 plus padding, so 2-decimal weights clip. The category column is 70 x scale (80): "Literature", "Container", "Clothing" cut to "Liter...", "Conta...". The Equip list's SLOT column already cuts to one letter at Small ("I...", "W...").
  3. RECOMMENDApply Large once: keep Large's own heights as they are and stop multiplying them by 1.15 (or keep 1.15 and use Small's heights; the result is the same: row 34, button 30). Literal widths and padding still grow 1.15 so columns keep pace with the text. The same bag shows 18 of 20 at Large.
  4. RECOMMENDColumns measured, not guessed: weight and count columns sized from the widest value in view in the current font ("88.88"), category from the widest category in view, capped at 96. Measured once per change of text size or list.
  5. RECOMMENDTruncation rules: (1) a column that cannot show four letters drops out (cond first, then category, as today) instead of showing "I..."; (2) a name keeps its end, so a stack's count and a "(Worn)" survive: "Vehicle Key - Chev... x5", not "Vehicle Key - Chevalier ..."; (3) the full name is always in the item card and the hover hint is not needed.
  6. ALTERNATIVEA third size between them (Small 13 / Medium 14 / Large 15) instead of tuning Large. More to test on every surface; not needed once Large is fixed.
