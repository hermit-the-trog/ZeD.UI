Padlock codes

Vanilla's combination padlock is set and opened in a small grey pop-up in the middle of the screen: three text boxes with ^ and v, OK and Cancel. The removal pop-up is titled "Set your Code", a wrong code closes it without a word, a code of 000 is refused without a word, and B on a controller presses OK. Here the crate's own lock card opens in the World window's card drawer, like the hutch and the trough: the padlock drawn as the dial (three wheels you turn), LOCK or REMOVE PADLOCK in the bar, vanilla's rules as NEEDS lines, the action's progress, and a plain answer when the code is wrong. The locked crate in the Loot strip opens it too. Switch the scenes above.

Decisions for you

  1. RECOMMENDA lock card in the card drawer. Vanilla's Use Combination Padlock and Remove Combination Padlock (the world menu on a crate, locker, counter or bar you built) walk next to it and open a pop-up mid-screen. Here both open the lock card in the World window, with the walk when you are out of reach and a leash like the other cards. Clicking a locked container in the Loot strip opens the same card; today that click does nothing.
  2. RECOMMENDThe dial is the padlock. Three number wheels on the lock's face, each with a ▲ and a ▼; the mouse wheel turns the wheel under the pointer and the number keys type the code left to right (Backspace steps back). The shackle shows the state: up while you set a code, down while it is locked; once the padlock is off the card says so. Vanilla's three text boxes go.
  3. RECOMMENDVanilla's rules, said out loud. LOCK needs a Combination Padlock in your bags and a code other than 000 (vanilla quietly refuses 000; the card says so). A locked crate is shut to everyone, you included, until the code takes the padlock off, and the card says that before you lock it. REMOVE PADLOCK with the right code puts the padlock back in your bags. Both run vanilla's own action, with the progress band and STOP.
  4. RECOMMENDA wrong code says so. Vanilla's pop-up closes and nothing happens, so you cannot tell a wrong code from a slip. The card runs every try as the same short action, then either takes the padlock off or says "Wrong code" in the footer and leaves the wheels where you set them. A try costs the same moment whether right or wrong, so the card does not make guessing faster than vanilla's menu.
  5. RECOMMENDKey padlocks on the same card. A crate with a key padlock shows the key that fits, whether you carry it, and REMOVE PADLOCK (vanilla's Remove Padlock); an unlocked crate offers USE COMBINATION PADLOCK and USE PADLOCK when you carry one. A locked container in the Loot strip gets a small padlock mark, so its dim button explains itself.
  6. YOUR CALLRemember the code you set. Vanilla keeps no record: forget the code and the crate stays shut until you break it. Option: the lock remembers who set it, and for that character the wheels open on the code with a SET BY YOU line (scene "Your own crate"); anyone else sees an ordinary lock. Leaving it out keeps vanilla's stakes.
  7. Vanilla bugs fixed on the way. The removal pop-up is titled "Set your Code"; B on a controller presses OK instead of Cancel; closing the pop-up drops the game speed back to normal; two digits typed into one box break the code (a 12 in the first box reads as 1200 and more).
  8. On a controller. D-pad left and right pick a wheel, up and down turn it, A presses LOCK or REMOVE PADLOCK, B closes the card. The Loot strip's locked button takes A like any container.
