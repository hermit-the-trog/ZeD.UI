Mods: turning a mod's files off

A new Files tab in a mod's info pane lists the mod's code files, each with an on/off switch. Turn off a part of a mod that has no setting of its own, or find which file is behind an error or a problem. It works the way file picks do: ZeD puts an empty copy of the file into its ZeD picks helper mod, which loads last, so the empty copy is the one the game runs. A reload puts it in place, no restart. Single player only. The mod, its files and its error are real (Bandits Week One, as subscribed).

Decisions for you

  1. RECOMMENDA Files tab beside Conflicts, for every mod that has code files. Files are grouped by folder (client, server, shared) with their size; Find narrows them by name. A switch per file. A dot marks what you changed since the screen opened.
  2. RECOMMENDSay what turning a file off will touch, before it happens. ZeD reads the mod's other files for the file's name (its table name, a require of it). Used by 0: safe to turn off on its own. Used by 4: those 4 will likely error, and the band names them and offers Turn off anyway. This is found by reading text, so it can miss a use; the band says so.
  3. RECOMMENDErrors sit on the file they come from. The game's error names the file and line (BWOScheduler.lua, line 42), so the Files tab marks that file with its count and links to the error in Messages. When the error's file is used by many others, the band says turning the mod off for this save is likely the better fix.
  4. RECOMMENDFind the file behind a problem, for a problem with no error to point at: ZeD turns half the files off, you reload and check, and say whether it still happens; each answer halves what is left. About 7 rounds for 108 files. Stop and put all back at any round. It says up front that this can break the mod in other ways and to use a copy of the save.
  5. RECOMMENDKept until you turn it back on. The list shows 1 file off on the mod's row; ZeD picks shows in the list as always. Turn all back on on the Files tab undoes it for that mod. When Steam updates the mod, files that are off stay off by path; a file the update removed shows as gone.
  6. LIMITCode files only (Lua). The game lets a mod write text files, not pictures or sounds, so textures, models, sounds and maps cannot be switched. Script files (items, recipes, vehicles) are text, but the game reads scripts across all mods by file name, and whether an empty copy would remove a mod's items is not tested; not offered in v1. Translation files are not offered either.
  7. LIMITSingle player only. A server checks that each player's code files match its own, so a turned-off file would keep you out of a server, as file picks would.
  8. LIMITA file that is turned off still loads, empty. Anything that requires it gets an empty result instead of an error at that line, and the error moves to the first place that uses what the file defined. That is what Used by warns about.
  9. YOUR CALLWhere troubleshooting starts. Shown here as a button on the Files tab. It could also start from an error in Messages (Find the cause), for errors that point at the game's own code rather than at a mod's file.
  10. Controller: the file list is a column of stops; A flips the switch, X opens the band's actions, LB / RB walk the info pane's tabs as today.
